# CECS-399-499

Repository for working on CECS 399/499 capstone project


**Intro**

As energy demands increase in the United States the risk and consequences from grid outages grows. However, current grid outage detection models are often complex, hard to interpet, as well as hard for consumers to access. This project works to create an end-to-end pipeline for interactive outage risk and assessment using open source data and software. 
   
**Dataset introduction**

Population data was taken from the U.S. Census Bureau in 2020-2025 to see the changes in population across Tennessee and used to weight area scores higher or lower based on population. Energy grid areas that serve larger populations face greater stress.
U.S. Census Bureau.

(2025, May 15). Annual estimates of the resident population for incorporated places in Tennessee: April 1, 2020 to July 1, 2024 (SUB-IP-EST2024-POP-47) [XLSX]. Population Estimates Program.
